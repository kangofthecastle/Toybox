# Toybox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build three pure-stdlib, super-lightweight Windows desktop toys (System Monitor HUD, Clipboard History, Music-Reactive Pet) plus a system-tray launcher.

**Architecture:** Pure-logic already lives in root modules (`clip_history`, `beat_detector`, `sysmetrics`, `config`) with 36 passing unit tests. This plan adds a focused `winkit/` package wrapping the native Win32/ctypes/winreg calls (one responsibility per submodule), then the four `.pyw` entry scripts that compose those pieces. Each toy is an independent process; only the launcher owns a Win32 message loop + the single tray icon.

**Tech Stack:** Python 3.12 stdlib only — `tkinter`, `ctypes`, `winreg`, `unittest`. Launched via `pythonw.exe`. No pip installs.

## Global Constraints

- **Stdlib only.** No third-party imports anywhere. (verbatim: "standard library only ... Zero pip installs")
- **Super lightweight** is a hard requirement: HUD/metrics 1 Hz; clipboard change-poll ~4 Hz, hotkey-poll ~15 Hz; pet 30 Hz active / ~8 Hz idle (idle after ~2 s silence). Redraw only on change.
- **No disk-persisted clipboard.** History is in-memory only.
- **No network, no telemetry.**
- **64-bit-safe ctypes:** set `.argtypes`/`.restype` on every Win32 call; use `GetWindowLongPtrW`/`SetWindowLongPtrW` and `LRESULT = c_ssize_t`. (per `docs/superpowers/specs/2026-06-24-native-gotchas.md` risk #2)
- **`pythonw` stream guard:** every `.pyw` calls `winkit.startup.guard_streams()` as its first executable line (per gotchas risk #4).
- **Reference:** `docs/superpowers/specs/2026-06-24-native-gotchas.md` contains the validated, copy-ready ctypes patterns for every native task below. Implementations adapt those patterns; follow their "Watch out for" lists exactly.
- **Config path:** `os.path.join(os.path.dirname(os.path.abspath(__file__)), "config.json")` resolved per script (cwd is System32 at login).

**Testing approach:** Pure functions get strict unit TDD (`test_winkit_pure.py`). Native wrappers that need the real OS get real-system integration tests (`test_winkit_system.py`) asserting sane ranges/round-trips — valid because we run ON the target (Windows 10). GUI scripts get a **smoke harness**: each `.pyw`, when env `TOYBOX_SMOKE=<ms>` is set, builds its UI, schedules `root.after(<ms>, destroy)` (and the launcher a self-quit timer), runs briefly, and exits 0 — the test asserts exit code 0 and empty stderr.

### Task 1: `winkit/window.py` — DPI + overlay ex-styles

**Files:**
- Create: `winkit/__init__.py`, `winkit/window.py`
- Test: `tests/test_winkit_system.py` (new)

**Interfaces:**
- Produces:
  - `enable_dpi_awareness() -> None` — call ONCE before `tk.Tk()`.
  - `KEY_COLOR: str = "#010101"` — sentinel transparent-color; never paint with it.
  - `apply_overlay_styles(window, *, clickthrough: bool = False, tool_window: bool = True, no_activate: bool = False) -> int` — `window` is a realized tk root/Toplevel (caller did `window.update()` first). Read-modify-writes `GWL_EXSTYLE` (OR-in `WS_EX_LAYERED|WS_EX_TOOLWINDOW`, plus `WS_EX_TRANSPARENT` if clickthrough, plus `WS_EX_NOACTIVATE` if no_activate or clickthrough), then `SetWindowPos(SWP_FRAMECHANGED|SWP_NOACTIVATE|NOMOVE|NOSIZE|NOZORDER)`. Returns the hwnd int.
- Consumes: nothing.

**Implementation:** Adapt the validated recipe in gotchas §1. Use `GetWindowLongPtrW`/`SetWindowLongPtrW` with `getattr` fallback to the 32-bit names; `restype/argtypes = c_void_p`. Resolve hwnd via `user32.GetParent(window.winfo_id()) or window.winfo_id()`. The caller (toy) owns `overrideredirect`, `-topmost`, `-transparentcolor`/`-alpha`, and geometry.

- [ ] **Step 1: Write the failing test** (in `tests/test_winkit_system.py`)

```python
import os, unittest, tkinter as tk
import winkit.window as W

GWL_EXSTYLE = -20
WS_EX_LAYERED = 0x00080000
WS_EX_TRANSPARENT = 0x00000020

@unittest.skipUnless(os.name == "nt", "Windows only")
class TestOverlayStyles(unittest.TestCase):
    def test_apply_overlay_sets_layered_and_clickthrough_bits(self):
        W.enable_dpi_awareness()
        root = tk.Tk(); root.withdraw(); root.overrideredirect(True)
        root.geometry("50x50+0+0"); root.update()
        try:
            hwnd = W.apply_overlay_styles(root, clickthrough=True)
            self.assertIsInstance(hwnd, int)
            import ctypes
            getp = getattr(ctypes.windll.user32, "GetWindowLongPtrW",
                           ctypes.windll.user32.GetWindowLongW)
            getp.restype = ctypes.c_void_p
            ex = int(getp(hwnd, GWL_EXSTYLE) or 0)
            self.assertTrue(ex & WS_EX_LAYERED)
            self.assertTrue(ex & WS_EX_TRANSPARENT)
        finally:
            root.destroy()
```
